Häufige Fragen

Welche Windows-Version wird benötigt? Das Store-Paket ist für x64-Windows ab Build 19041 ausgelegt. Ein zusätzlicher Bildschirm oder ein kompatibles USB-Panel ist nur für den jeweiligen Ausgabeweg nötig. Nicht jedes USB-Display wird unterstützt. Android-Ausgabe benötigt die Companion-App und eine Verbindung zum PC, etwa WLAN oder USB-Tethering; sie ist kein Bestandteil des Windows-MSIX.

Wo sind meine Daten? Die Store-Version speichert ihre Daten im Paketordner LocalState. Die Standalone-Version behält ihren separaten Datenordner. Vor einem Wechsel beide Apps beenden. Der dokumentierte Import kopiert ausgewählte Daten ausdrücklich und überschreibt keine vorhandenen Zieldateien; die Quelle bleibt erhalten. Keine vollständigen Konfigurationsdateien öffentlich anhängen.

Updates und Autostart? Store-Updates liefert Microsoft nach deinen Windows-/Store-Einstellungen. Den Autostart aktiviert der Benutzer in ScreenBuddy; Windows-Richtlinien können ihn verhindern. Die Registry-Autostart-Einstellung der Standalone-Version wird nicht automatisch umgestellt.

USB-Anzeige bleibt leer? Kompatibilität, Kabel und den ausgewählten COM-Port prüfen. Hersteller-Software kann den Anschluss belegen. Die Store-App kann den laufenden Hersteller-Prozess mit deinen vorhandenen Benutzerrechten beenden; dessen Autostart verwaltest du außerhalb von ScreenBuddy über die Windows-Aufgabenplanung, bei Bedarf mit einem Administrator.

Companion verbindet sich nicht? PC-Adresse und erreichbaren Port, Netzwerk/Tethering, Firewall und die richtige Kopplung prüfen. Keine Kopplungscodes veröffentlichen. Nach einem Gerätewechsel ggf. die alte Verbindung in der Companion-App vergessen und neu koppeln. Nicht ungefragt Windows-Daten oder Android-App-Daten löschen.

FPS steht auf n/a? Game-Mode aktivieren und eine passende Ansicht wählen. ETW benötigt die passenden Windows-Rechte; „FPS-Berechtigung prüfen“ beschreibt den Weg über einen Administrator und die Gruppe „Leistungsprotokollbenutzer“, danach ab-/anmelden. Die Store-App ändert keine Gruppen selbst. ScreenBuddy vor einem Anti-Cheat-Spiel starten. Bereits vorhandene Rechte oder lesend bereitgestellte HWiNFO-PresentMon-Werte können genutzt werden; nicht jede Messquelle ist immer verfügbar.

Drittanbieter oder KI-Werte fehlen? Die betreffende Integration und deren Einrichtung prüfen. Anbieter können eigene Konten/Schlüssel verlangen und ihre Schnittstellen ändern. KI-Kontozugriff ist freiwillig, separat zu bestätigen und abschaltbar. Fehlende Werte sind n/a, keine geschätzten Livewerte.

Companion-Automatik (ab 1.1.0)? Erst koppeln und die manuelle Anzeige prüfen. Die optionale Automatik sucht den PC lokal per mDNS bzw. TCP-Erreichbarkeit. Android kann Hintergrundstarts und Alarme verzögern. Benachrichtigungen und gegebenenfalls „Über anderen Apps anzeigen“ in den Android-Einstellungen prüfen. Die optionale Geräteadmin-Freigabe für Bildschirmsperren gibt es nur auf unterstützten Handys; sie kann vor einer Deinstallation in Android zu widerrufen sein. Keine Firewall-/Sperreinstellungen pauschal abschalten. Details stehen in der aktuellen Companion-Anleitung.

Eine hilfreiche Fehlermeldung senden

Nenne Windows-Build, ScreenBuddy-Version, Store oder Standalone, Ausgabeweg/Gerätemodell, genaue Schritte und erwartetes/tatsächliches Verhalten. Bei Companion zusätzlich dessen App-Version und Android-Version nennen. Verwende Beispieldaten für Bilder. Entferne Namen, private URLs, Tokens, Passwörter, Kopplungscodes und persönliche Inhalte aus Protokollen und Screenshots. Öffentliche GitHub-Issues sind öffentlich sichtbar; sende vertrauliche Angaben nicht dorthin.

Common questions

Which Windows version is required? The Store package targets x64 Windows build 19041 or newer. An additional monitor or compatible USB panel is needed only for that output type. Not every USB display is supported. Android output requires the separate Companion app and connectivity to the PC, such as Wi-Fi or USB tethering; the APK is not included in the Windows MSIX.

Where is my data? The Store edition uses its package's LocalState. The standalone edition retains its separate data directory. Close both apps before switching. The documented explicit import copies selected data without overwriting destination files and preserves the source. Do not attach complete configuration files publicly.

Updates and startup? Microsoft delivers Store updates according to Windows/Store settings. Users enable startup in ScreenBuddy; Windows policies can prevent it. The standalone edition's Registry startup setting is not changed automatically.

Blank USB panel? Check compatibility, cable and selected COM port. Vendor software can occupy the port. The Store app can stop a running vendor process with your existing user privileges; manage its startup outside ScreenBuddy in Windows Task Scheduler, with administrator assistance if needed.

Companion cannot connect? Check the PC address, reachable port, network/tethering, firewall and correct pairing. Never publish pairing codes. After a device change, forget the previous PC connection and pair again if needed. Do not delete Windows or Android app data without considering existing pairings.

FPS shows n/a? Enable Game Mode and select a suitable view. ETW needs the relevant Windows permissions; “Check FPS permission” explains administrator-assisted membership of “Performance Log Users”, followed by signing out and back in. The Store app does not change group membership itself. Start ScreenBuddy before an anti-cheat game. Existing permissions or read-only HWiNFO PresentMon readings can be used; measurement sources are not always available.

Third-party or AI values missing? Check the enabled integration and its setup. Providers can require their own accounts/keys and change interfaces. AI account access is optional, separately confirmed and can be disabled. Missing values are n/a, not invented live measurements.

Companion automation (from 1.1.0)? Pair and check manual display first. Optional automation discovers the PC locally through mDNS or a TCP availability check. Android can delay background starts and alarms. Check notification permission and, if needed, “Display over other apps” in Android settings. Optional device-administrator screen locking is available only on supported phones; you may need to revoke it in Android before uninstalling. Do not broadly disable firewalls or screen locks. See the current Companion guide.

Send a useful report

Include Windows build, ScreenBuddy version, Store or standalone edition, output type/device model, exact steps, expected result and actual result. For Companion, also include its app version and Android version. Use sample data in images. Remove names, private URLs, tokens, passwords, pairing codes and personal content from logs and screenshots. GitHub issues are public; do not send private information there.
